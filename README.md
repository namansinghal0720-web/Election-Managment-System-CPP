# Election Management System

A modular Election Management System developed in C++ using Object-Oriented Programming principles and STL.

## Features

- Candidate Registration
- Voter Registration
- Multiple Elections
- Vote Casting
- One Vote Per Voter
- Result Declaration
- Tie Detection
- Candidate Ranking
- Exception Handling
- Menu Driven Console Application

## Tech Stack

- C++
- STL
- Object Oriented Programming
- VS Code
- Git

## OOP Concepts Used

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Exception Handling

## Data Structures Used
